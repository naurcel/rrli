New Workflow /deliveries/import

1. Dedicated Multi-Step Data Import

Moved importing out of popup dialogs into a full-page, 4-step wizard. Supports RFC 4180 CSV, TSV, and DSV files up to 10MB.

  • ✔ Multi-Stop Aggregation: Automatically consolidates repeated waybills into one trip with sequential store drop-offs.
  • ✔ Inline Staging Table: Real-time editing and re-validation with status tabs (Ready, Attention, Duplicates).
  • ✔ Non-Destructive Commit: Existing waybills are detected and safely skipped with error report generation.
UX Refinement /deliveries/[id]

2. Delivery Navigator & Searchable Dropdown

Replaced the horizontal scrollbar of delivery tags with a clean, searchable select dropdown and adjacent previous/next buttons.

  • ✔ Switch directly between deliveries without navigating back to the main ledger.
  • ✔ Instant search filter inside dropdown by waybill, client, or date.
  • ✔ Minimal, understated badges replacing heavy colored pills.
New Component ImageViewerModal

3. In-App Document Lightbox Viewer

PODs, delivery documents, and truck photos now open immediately in an in-app lightbox modal rather than forcing a new browser tab.

  • ✔ Zoom in/out, pan, reset zoom, and 90° rotation controls.
  • ✔ Right-click allowed for users who still prefer opening images in a separate tab.
  • ✔ Accessible keyboard shortcuts: Esc to close.

Rebalanced the vehicle profile layout so the truck image is wider, preventing the KPI cards from stretching unnaturally.
