# Development Overview

Build RouteX as one Next.js 15 App Router application using React, TypeScript, Tailwind CSS, shadcn/ui, and Lucide React. Use Next.js Server Actions and Route Handlers for server logic, PostgreSQL through Supabase for structured data, Auth.js for authentication, Supabase Storage for private POD files, and Vercel as the proposed deployment platform. Use npm. No Prisma or separate backend app under the current constraints.

Before implementation, resolve business rules and access-control blockers in [Issues and TODOs](../08-Logs/Issues-and-TODOs.md). Validate Auth.js/Supabase integration and schema/migration approach in a technical spike.
