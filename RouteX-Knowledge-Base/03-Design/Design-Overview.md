# Design Overview

The design packages and prototype point toward an information-retrieval and record-review interface rather than a marketing page or live control center. Prefer clear hierarchy, readable tables, strong search/filter affordances, generous whitespace, and drawers/dialogs for contextual edits where the existing design system supports them.

Known design direction from working UI materials:
- Readex Pro typography appears in the design guidance.
- Light theme is primary, with optional dark/system appearance if retained.
- Sidebar can be collapsed; global search and date filtering are important interactions.
- Avoid maps, hero marketing sections, futuristic control-center visuals, dense analytics walls, and generic KPI grids.
- Make financial results traceable to source records.

These are design intent. Verify against the latest blueprint and user-confirmed decisions before implementation. The HTML prototype uses sample/mock data and does not establish backend functionality.
