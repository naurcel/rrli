# Navigation and Global Search

Prototype navigation includes Dashboard, Deliveries, Fleet, Transactions, Reports, Administration, and Settings. The working feature catalog also includes HR/compensation and profitability analysis, which may appear as a standalone section or through reports/record views; final information architecture must reconcile these labels.

Search and date filtering are primary interactions. Search must respect role permissions and return historical records for deactivated reference entities. Do not assume a particular navigation label is final if it conflicts with the accepted feature catalog.
