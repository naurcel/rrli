# Layout, Responsive Design, and Accessibility

- Keep search and date filters easy to find in list/report contexts.
- Prioritize information hierarchy and readable data density over decorative dashboards.
- Use responsive layouts for the supported browser/display context; exact mobile/tablet acceptance scope is TBD.
- Provide keyboard-accessible controls, visible focus, labels, semantic headings, and sufficient contrast.
- Do not rely on color alone to communicate missing POD, incomplete financial records, or voided status.
- Exact accessibility target and browser support matrix are TBD; agree on measurable acceptance criteria before final QA.
