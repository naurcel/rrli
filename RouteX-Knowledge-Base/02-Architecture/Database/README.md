# Database Design

This directory contains the conceptual data model and relationship notes. The final schema has not been approved or verified as implemented. Treat any ERD images, entity lists, and candidate schema files in the source packages as proposals until reconciled against business rules.

Likely data areas include users/roles, trucks, clients, employees/crew, completed deliveries, delivery financial entries, company expenses, compensation summaries, POD metadata, and audit events. Exact entity names, field names, keys, constraints, and cardinalities remain TBD.
