# Feature and Module Catalog

| Module | Purpose | Status/notes |
|---|---|---|
| Dashboard | Period summary, authorized metrics, links to source records | Exact metrics/role visibility TBD |
| Delivery Management | Completed delivery records, revenue/expenses, POD | Core in-scope feature |
| Fleet Management | Truck registry and delivery history | Core in-scope feature |
| Financial Management / Transactions | Company expenses not attributed to a specific delivery | Core in-scope feature |
| HR / Compensation Summaries | Employee/crew information and period compensation summaries | In scope at summary level; not full payroll |

| Search | Search/filter/retrieve historical records | Core in-scope feature |

Names may differ between documents and prototypes. Use this catalog as a readable index, not as authority to add unapproved scope.
